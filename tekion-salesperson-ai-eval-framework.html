Tiered Evaluation Pipeline — Working Prototype

Where prevention is cheap, and where it has to become detection.

Salesperson AI sends real messages to real leads with no human approval per message — which means a full LLM-as-judge + confidence check can't sit on the send path; it's too slow for a product whose entire value is speed. This traces three real message types through the three-tier design that resolves that: cheap real-time checks for the known failure patterns, async judge scoring for everything nuanced enough to need it.

Revision note: an earlier version of this demo proposed a single pre-send gate combining judge + confidence scoring. That doesn't hold up under a latency budget — this version reflects the corrected architecture.
Target agent · Salesperson AI (CRM AI)
Real-time layers · Tier 0 + Tier 1
Async layer · Tier 2 — LLM-as-judge + confidence
01 — The Three Tiers
Tier 0

Topic routing

A lightweight classifier reads the lead's message before generation. High-risk topics (financing approval, legal terms, complaints) skip autonomous send entirely and go to human-assist drafting.

Runs before generation · near-zero latency
Tier 1

Deterministic checks

Rule-based pattern match and a live-inventory lookup on the drafted reply — guarantee language, price/availability mismatch. No model call.

Runs in the send path · near-zero latency
Tier 2

Judge + confidence

Full 5-dimension rubric scoring plus an objective confidence signal, run on every autonomously-sent reply — after it's already out.

Runs async, post-send · seconds, off the critical path

03 — Tier 2 Judge Prompt (Abridged)
# runs async, on every autonomously-sent reply — never on the send path You are grading one turn of a dealership sales-chat agent. Given: the lead's message, the agent's reply, and the ground-truth context (live inventory snapshot, deal record, dealer FAQ config) Score each dimension 1–5 using only the rubric definitions provided. If any claim in the reply cannot be verified against context, cap Grounding Accuracy at 2. If escalation was warranted and did not happen, cap Escalation Judgment at 2. Output: {"dimension": score, "rationale": "one sentence, cite the specific span"} per dimension.

05 — How Each Tier Actually Runs
Tier 0

Prevention — known categories

Small classifier, no full LLM call. Retrained on a defined cadence using confirmed Tier 2 violations as new training signal — this is the layer that gets broader over time.

Tier 1

Prevention — known patterns

Regex + live-inventory lookup, no model call. Deliberately narrow — it only catches what it's explicitly been told to look for, which is exactly why Tier 2 exists.

Tier 2

Detection + remediation

Full judge + confidence, distilled model on 100% of traffic, frontier model cross-checking 5–10% for drift. Never gates send — its job is speed-to-catch, not prevention.
